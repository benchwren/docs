# benchwren.com

Public site for Benchwren apps: product docs, data and security notes, and later the legal and support pages.

- Built by GitHub Pages with Jekyll and the [Just the Docs](https://just-the-docs.com/) theme (`remote_theme` in `_config.yml`). There's no build step here: push to `main` and Pages rebuilds.
- Served at `https://benchwren.com` (see `CNAME`). DNS is at Cloudflare and must stay **DNS only** (grey cloud) so GitHub can issue the HTTPS certificate.
- One folder per app, such as `component-tree/`.
