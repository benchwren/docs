# Atlassian apps

Benchwren apps for Jira Cloud, sold on the Atlassian Marketplace. Each one is built on Atlassian Forge and runs entirely on Atlassian's cloud.

| App | What it does |
|---|---|
| [Component Tree for Jira](component-tree/) | Arrange Jira components into a tree, search a whole branch with `componentBranch`, and show each work item's component path. |
| [Sprint Scope for Jira](sprint-scope/) | Search sprint scope change: what was in a sprint at the start, what was added after it started, and what was removed. |
